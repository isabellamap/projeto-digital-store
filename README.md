# Pequenos Encantos — Digital Store

## Sobre o projeto

A Pequenos Encantos é uma loja virtual de produtos artesanais, desenvolvida como projeto final do curso de Desenvolvimento Full Stack.

A plataforma apresenta produtos feitos à mão, como bastidores bordados e amigurumis, permitindo que os usuários conheçam os produtos, visualizem seus detalhes e realizem personalizações.

## Funcionalidades

- Página inicial com banner e categorias.
- Listagem de produtos.
- Busca por nome.
- Filtro por categoria.
- Ordenação por preço.
- Página de detalhes dos produtos.
- Campo para personalização.
- Sacola de compras.
- Adição e remoção de produtos.
- Controle de quantidade.
- Cálculo automático do valor total.
- Layout adaptável para dispositivos móveis.

## Tecnologias utilizadas

- React
- JavaScript
- HTML
- CSS
- Vite
- Git e GitHub

## Como executar o projeto

1. Clone este repositório:

   `git clone https://github.com/isabellamap/projeto-digital-store.git`

2. Acesse a pasta:

   `cd projeto-digital-store`

3. Instale as dependências:

   `npm install`

4. Inicie a aplicação:

   `npm run dev`

5. Abra no navegador o endereço indicado pelo Vite, normalmente `http://localhost:5173/`.

## Identidade visual

A loja utiliza uma identidade visual delicada e moderna, com tons de rosa, lilás e cores claras, valorizando o caráter artesanal dos produtos.
